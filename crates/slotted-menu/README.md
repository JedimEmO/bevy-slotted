# slotted-menu

Game menus for [slotted](https://github.com/JedimEmO/bevy-slotted): a main
menu, pause, settings with persistence, confirm dialogs, toasts, text pages
and a hint bar, shipped as screen templates a game inherits from and a mod
injects into. Menus M2 contract: `docs/design/menus-m2-contract.md`.
